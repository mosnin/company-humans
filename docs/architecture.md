# Architecture

Company Human is a separate product. The current code contains only a Next.js web scaffold and shared visual primitives from Company OS Web. The planned planes in the canonical Notion specification are identity, control, commercial, human workspace, events, attribution and commission, developer integration, and specialized product data. None are implemented yet. Specialized products remain independent sources of truth.

See [migration assessment](migration-assessment.md) for the source audit and recorded auth/database incompatibility.
